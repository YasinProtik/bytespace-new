ByteSpace

ByteSpace is a modern online learning platform built with React and TypeScript. Users can browse courses, explore creators, create accounts, log in, and access their dashboard.

Technologies

-React

-TypeScript

-TanStack Start & Router

-Vite

-Tailwind CSS

-Radix UI

-Supabase

-PostgreSQL

-React Hook Form

-Lucide React

Main Features

-Homepage

-Course browsing

-Course details

-Creator profiles

-Login & Signup

-User Dashboard

-Responsive design

-supabase authentication

Run Locally

Clone the repository:

git clone https://github.com/YasinProtik/bytespace-new.git
cd bytespace-new


Install dependencies:

npm install

Start the development server:

npm run dev

Then open the URL shown in the terminal, usually:


http://localhost:5173

Build

npm run build

Deployment

The project can be deployed using Vercel.

Build command:

npm run build

Make sure the required Supabase environment variables are added to Vercel.
